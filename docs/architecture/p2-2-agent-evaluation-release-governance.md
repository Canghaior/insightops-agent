# P2.2-A/B/C Agent 评测与发布治理

## 目标

P2.2 把 Prompt、模型参数和工具合同的变更从“直接修改生产配置”升级为可复现、可比较、可审计的发布流程：A 建立不可变评测集并复用真实 AgentLoop 执行；B 建立候选版本、工具合同指纹和生产激活闸门；C 提供管理页面、基线趋势、逐案例 Trace 和失败 Run 反馈闭环。

这不是允许评测任务修改生产数据的实验平台。评测 Run 只暴露 `READ_ONLY` 工具，服务端还会在直接调用和条件任务图两个入口拒绝写工具。

## P2.2-A：版本化评测集与真实链路评测

Owner 或系统管理员可以创建锁定的评测集版本。每个案例记录：

- 问题、期望工具、禁止工具和必须命中的官方来源域名；
- 是否要求观察失败恢复、最大工具轮次；
- 单案例耗时、Token、估算成本上限以及是否为必过案例。

数据集同时保存成功率、工具选择准确率、恢复率、引用满足率、平均耗时、平均 Token 和平均成本七类聚合门槛。评测服务异步逐案例调用真实 `AgentLoopService`，继续使用现有 Planner、Registry、DAG、重试、熔断、预算和成本账本，而不是用模拟答案替代执行。

每个评测案例创建独立 `agent_run`，但标记为 `run_kind = 'EVALUATION'`，不会进入普通用户的会话执行记录列表。案例结果保留 Agent Run ID，可从管理页打开完整 PLAN、TOOL、OBSERVATION 和工具尝试 Trace。

聚合通过要求所有必过案例通过，且七类指标同时满足数据集门槛。没有恢复预期案例时，恢复率按 100% 处理，避免无适用样本把版本错误判为失败。

## P2.2-B：候选版本与生产激活闸门

候选版本包含：

- Planner Prompt 附加指令；
- 模型名称、temperature 和最大输出 Token；
- 创建时计算的工具合同 SHA-256 指纹；
- 可选的上一个候选版本、最近评测时间和状态。

工具合同指纹来自当前 Registry 中按名称稳定排序后的工具名、风险等级、审批策略、超时和输入 Schema。启动评测和生产激活都会重新计算指纹；Registry 合同发生变化后，旧评测结果不能绕过闸门。

生产激活在单个数据库事务内完成，使用 Workspace 级 advisory lock 串行化并发操作。系统验证候选属于当前 Workspace、最近一次评测已通过、数据集仍有效且工具合同指纹一致，然后停用旧版本、激活新版本并写入审计。Agent Run 启动时读取当前 Workspace 的激活版本；未配置激活版本时继续使用应用默认模型参数，保证兼容现有环境。

## P2.2-C：管理、趋势与反馈闭环

`/admin/agent-evaluations` 面向 Workspace Owner 和系统管理员，提供：

- 创建不可变数据集和多案例质量/成本门槛；
- 创建 Prompt/模型/参数候选版本；
- 启动异步评测并轮询运行状态；
- 对比最近评测的成功率、工具准确率、恢复率、引用率、耗时、Token 与成本；
- 展开逐案例结果并跳转到对应 Agent Run Trace；
- 从已有失败 Run 派生新的回归案例，形成“线上失败 -> 评测集新版本 -> 候选重测 -> 激活”的闭环。

服务端暴露评测运行成功/失败、案例错误、运行中数量和耗时指标，便于后续接入生产告警与发布看板。

## 数据模型

- V30：`agent_evaluation_dataset`、`agent_evaluation_case`；
- V31：`agent_release_candidate`、`agent_runtime_release`、`agent_release_activation_audit`；
- V32：`agent_run.run_kind`、`agent_evaluation_run`、`agent_evaluation_case_result`。

数据集和案例以版本化新记录表达变更，不原地修改已锁定基线。评测 Run 保存聚合指标和可选基线 Run；案例结果保存断言、性能、成本、错误码及关联 Agent Run。

## 安全与当前边界

- 评测只能由 Owner 或系统管理员发起，且只能访问当前 Workspace 数据。
- 评测模式不暴露写工具；即使 Planner 构造写节点，服务端也会以 `EVALUATION_WRITE_TOOL_FORBIDDEN` 拒绝。
- 激活要求真实通过记录与工具合同指纹一致，不能仅修改候选状态绕过。
- 当前采用单实例异步执行器；服务进程重启时尚未实现分布式队列接管和自动恢复未完成评测。
- 当前是技术质量发布门禁，不包含 A/B 流量切分、自动回滚、套餐、支付或财务级成本核算。
