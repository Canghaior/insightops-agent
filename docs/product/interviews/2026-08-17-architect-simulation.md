# 架构师 Alpha 工作流模拟

> 日期：2026-08-17
>
> 方式：由项目负责人授权，使用真实本地页面、DeepSeek 和 GitHub Release 链路进行角色模拟

## 角色任务

一名负责 Java AI 框架选型的架构师，需要比较 Spring AI 与 LangChain4j 的近期发布活跃度，并区分事实、推断和证据缺口。

## 测试过程

1. 比较两个项目最近 90 天的正式 Release 数量和最近发布日期。
2. 追问“根据刚才相同的 90 天证据，哪个项目发布更活跃”。
3. 询问仅靠 Release 数据无法证明的选型维度。

## 结果

- 首轮取得 21 条官方 Release 证据：Spring AI 5 条、LangChain4j 16 条。
- 追问正确继承两个项目和 90 天窗口，再次取得同口径 21 条证据，数量和结论一致。
- 回答将 Release 数量、日期列为事实，把“发布更活跃”限定为发布维度的推断。
- 对社区、Issue/PR、性能、生产案例、兼容矩阵等当前无法验证的内容明确提示人工补充。

## 验收中发现并修复

最初追问只继承项目、未继承 90 天窗口，导致重新查询的证据口径变化；同时模型曾自行计数出错。现已增加时间窗口继承和每项目结构化证据计数，并完成相同问题复测。

结论：修复后 PASS。
