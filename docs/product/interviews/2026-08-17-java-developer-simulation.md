# Java 开发者 Alpha 工作流模拟

> 日期：2026-08-17
>
> 方式：由项目负责人授权，使用真实本地页面、DeepSeek 和 GitHub Release 链路进行角色模拟

## 角色任务

一名正在 Spring Boot 项目中评估 AI 能力的 Java 开发者，需要快速确认 Spring AI 的可用基线并理解升级变化。

## 测试过程

1. 询问 Spring AI 最新稳定版本、发布日期和官方 Release 链接。
2. 不重复项目名，追问“它相比上一个稳定版本有哪些主要变化”。

## 结果

- 两轮均成功，使用同一会话，第二轮正确继承 Spring AI 项目上下文。
- 最新稳定版本回答为 v2.0.0，并引用 v2.0.0 与 v1.1.8 的 GitHub 官方 Release tag URL。
- 回答只陈述 Release 摘录支持的变化，并说明摘录截断和升级细节未披露。
- 发送后输入框清空，两轮消息同屏显示，刷新后可恢复。

结论：PASS。当前能力足以完成“确认试用版本 + 理解 Release 级变化”的初筛任务。
