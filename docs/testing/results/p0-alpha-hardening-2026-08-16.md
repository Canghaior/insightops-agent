# P0 Alpha 试用前加固结果

日期：2026-08-16

## 修复范围

- 前端、后端和 PostgreSQL 仅绑定本机回环地址。
- DeepSeek 回答和执行记录使用安全 Markdown 渲染，原始 HTML 会转义，只允许 HTTP/HTTPS 链接。
- 概览页改为准确描述“后端受控查询 Release，DeepSeek 基于证据回答”。
- 20 问评测集逐条验证项目识别、工具命中和时间窗口。
- “最近、近期、目前”但未显式给出天数的 Release 研究问题统一使用 90 天口径。
- GitHub Release 查询支持翻页，每个项目最多纳入 30 条；达到上限时向模型明确标记证据不完整，禁止声称完整列表或精确频率。
- 同一浏览器会话复用最近 12 条消息；指代型 Release 追问仅从最近一条用户问题继承项目，避免跨项目污染。
- 聊天页按顺序展示多轮消息，发送后清空输入框，刷新后从数据库恢复最近 100 条消息。

## 保留边界

- P0 仅提供当前浏览器标签页内的短期上下文；账号级、跨设备和可管理的长期记忆属于 P1。
- 20 问本次完成的是确定性路由契约，不代表20次在线模型答案均已人工判定；在线答案质量由 Alpha 验收记录补充。
- 自动测试没有调用在线 DeepSeek 或 GitHub；上表“真实两轮追问”是单独执行的在线浏览器验收。
