日期：2026-08-16

## 修复范围

- 发送问题后立即清空输入框。
- 支持 `Enter` 发送、`Shift + Enter` 换行，并兼容 `Ctrl + Enter` 发送。
- 同一聊天页连续显示多轮 USER/ASSISTANT 消息。
- 页面刷新后通过 `sessionId` 从 PostgreSQL 恢复最近 100 条消息。
- 流式回答追加到当前助手消息，并在接近底部时自动滚动。
- 失效浏览器会话返回 404 后清除本地会话 ID，不删除数据库记录。

3. 追问“它相比上一个版本有什么变化？”。
4. 确认两轮问题、两轮回答同时显示，第二轮正确继承 Spring AI。
5. 刷新研究问答页面。
