## 运行中的 JAR 文件锁说明

项目工作目录内的首次 `mvn verify` 已完成全部42个测试，但用户正在运行的后端进程锁定了目标 JAR，Spring Boot 插件无法将该文件重命名为 `.jar.original`。未中断用户进程；随后把不含 `.env`、构建产物和依赖的源代码复制到临时隔离目录，在相同数据库门禁下完成完整 `mvn verify`、Server/Worker 重新打包，并删除临时目录。这是 Windows 运行文件锁，不是代码或测试失败。
