# P1 账号管理验收记录（2026-08-17）

## 范围

- Flyway V8/V9：系统角色、账号审计表和旧 bootstrap 管理员升级
- `.env` 首个系统管理员初始化且重启不覆盖密码
- `SYSTEM_ADMIN / OWNER / MEMBER` 服务端权限矩阵
- 邀请制创建、启停、角色修改、密码重置
- 临时密码首次登录强制改密和会话撤销
- 管理端用户列表、账号操作、审计日志与个人密码页

## 自动验证

- Maven 全量测试通过，含 `AccountAdminServiceTest` 与 `AuthenticationFilterTest`。
- PostgreSQL 随机隔离 Schema 门禁通过，9 个迁移成功执行；验证 bootstrap 管理员、用户创建、角色、重置、停用和审计读写。
- 前端 ESLint、Vitest（4 个文件、12 项）和生产构建通过。

## 安全结论

- 没有公开注册 API 或页面。
- 权限校验位于服务端；直接调用管理 API 不能绕过角色规则。
- 临时密码明文只存在于管理员当次输入，不写入数据库或审计。
- 停用、重置和本人改密会撤销活动会话。
