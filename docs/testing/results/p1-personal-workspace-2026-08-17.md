## 安全边界

- 公共仓库不包含初始密码；`.env.example` 只提供空模板，真实密码仅放在被忽略的 `.env`。
- Bootstrap 只在凭据不存在时初始化，不会在每次启动重置用户密码。
- P1 当前为单工作区登录模型；注册、找回密码、OAuth、组织权限和管理员用户管理仍不在本轮范围。
