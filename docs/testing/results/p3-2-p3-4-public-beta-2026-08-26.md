## 4. 安全断言

- 总开关、服务就绪和数据库运行开关三层失败关闭；部署预检阻止缺少外部参数时误开注册。
- Turnstile 在服务端校验 token、hostname 与 action；失败和外部不可用不降级为放行。
- 注册名额由 PostgreSQL 原子分配，待验证申请过期释放，不允许超过 100。
- 公开 Run 开关由服务和 V40 触发器双层执行，不能只靠前端按钮。
- SES/CAM、Turnstile 和身份加密 Secret 只从环境读取，不进入 API、日志、导出或 Git。
- 免费 Beta 策略以硬限制强制每个 Workspace 同时最多 1 个 Run，不设置日/月普通使用额度。
- Caddy CSP 按 Turnstile 官方边界仅放行 `challenges.cloudflare.com` 的脚本与 Frame，并通过官方 Caddy 镜像校验。
- 导出文件 AES-256-GCM 加密，下载 token 只存哈希且一次性消费；快照排除认证 Secret，明文下载响应使用 `Cache-Control: no-store`。
- 删除需要密码和可选 MFA 复核，清理个人业务数据与上传文件、匿名化账号并释放名额；加密异地备份最多 30 天自然过期。
