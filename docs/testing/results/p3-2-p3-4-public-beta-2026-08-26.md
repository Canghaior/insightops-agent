## 3. 隔离运行态冒烟

在本机 PostgreSQL 18.4 隔离数据库和 127.0.0.1:18082 启动完整 Spring Boot JAR：

- Flyway 验证 40/40，schema 当前版本 40；
- `/api/v1/public/identity/registration/status` 返回 200；
- 外部配置未就绪时返回 `registrationEnabled=false` 和 `PUBLIC_BETA_CONFIG_DISABLED`，没有暴露 SES/Turnstile Secret；
- `/api/v1/system/status` 返回 200/UP；
- 匿名 `/api/v1/admin/public-beta` 返回 401；
- 带标准 CSRF 头的注册请求在关闭状态返回 503，未创建账号或占用名额。

首次真实启动发现 `PublicBetaService` 的测试构造器导致 Spring 无法选择生产构造器；已用显式 `@Autowired` 修复，并新增容器构造器回归测试。随后完整应用上下文和上述 HTTP 冒烟通过。

## 4. 安全断言

- 总开关、服务就绪和数据库运行开关三层失败关闭；部署预检阻止缺少外部参数时误开注册。
- Turnstile 在服务端校验 token、hostname 与 action；失败和外部不可用不降级为放行。
- 注册名额由 PostgreSQL 原子分配，待验证申请过期释放，不允许超过 100。
- 公开 Run 开关由服务和 V40 触发器双层执行，不能只靠前端按钮。
- SES/CAM、Turnstile 和身份加密 Secret 只从环境读取，不进入 API、日志、导出或 Git。
- 免费 Beta 策略以硬限制强制每个 Workspace 同时最多 1 个 Run，不设置日/月普通使用额度。
- Caddy CSP 按 Turnstile 官方边界仅放行 `challenges.cloudflare.com` 的脚本与 Frame，并通过官方 Caddy 镜像校验。
- 导出文件 AES-256-GCM 加密，下载 token 只存哈希且一次性消费；快照排除认证 Secret，明文下载响应使用 `Cache-Control: no-store`。
- 删除需要密码和可选 MFA 复核，清理个人业务数据与上传文件、匿名化账号并释放名额；加密异地备份最多 30 天自然过期。

## 5. 生产发布状态

代码部署时继续保持 `PUBLIC_BETA_ENABLED=false` 和数据库注册开关关闭。腾讯云模板审核、最小权限 CAM 凭据、真实运营者名称/联系邮箱和 Turnstile Secret 由运营者随后补齐；在真实邮箱完成注册、收信、验证、登录、导出与删除申请验收前，不打开公开注册。
