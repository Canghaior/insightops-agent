INSIGHTOPS AGENT

跟踪开源项目变化，带着来源回答问题

InsightOps Agent 是一个开源技术情报演示项目：关注 GitHub 项目更新，整理官方资料，并在问答中展示可核查的来源。适合查看从采集、检索到 Agent 回答的完整流程。

进入演示站点 查看 GitHub 源码

项目更新

跟踪已登记开源项目的 Release 和官方动态，查看变化来源。

资料检索

从少量指定官方页面和上传资料中检索相关片段，并附上引用。

连续问答

使用 DeepSeek 进行多轮问答；有来源证据时优先引用，证据不足时明确说明。

如何试用

目前为低访问量演示站点，账号由维护者提供。打开登录页即可使用已有账号；公开自助注册尚未开放。当前检索采用关键词模式，适合演示技术术语和明确的项目名称。
